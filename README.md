# Software Builder Portfolio

> Making Ideas Clickable.

一個以 **Software Builder** 為主題的作品集網站，展示如何將業務需求、工作流程與產品想法，快速轉換成可操作、可驗證、可部署的軟體原型。

## Overview

這個作品集收錄多個前端專案與工具範例，涵蓋：

- 製造管理系統
- Email 模板編輯器
- Excel 檔案預覽工具
- 條碼 / QR Code 掃描工具
- 互動式小遊戲

每個作品都提供：

- 線上 Demo
- 原始碼 Repo
- 功能說明
- 使用情境介紹

目的不是展示畫面，而是展示：

> 如何把需求轉換成真正能使用的軟體。

## Design Concept

### Expanded Hero

首頁以大型 Hero 區塊呈現：

- 個人定位
- 核心能力
- Software Builder 品牌形象

### Compact Header

當使用者向下捲動時：

- Hero 區塊淡出
- Compact Header 淡入
- 保持品牌識別與快速導覽
